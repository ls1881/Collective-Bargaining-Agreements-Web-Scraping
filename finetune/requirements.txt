# Split into three files because this pipeline runs across three different environments with
# incompatible dependency needs (notably: vLLM pins its own torch build that conflicts with the
# training stack's torch if installed together).
#
#   requirements-local.txt   local M3 Max / any CPU machine — data prep, labeling, review
#   requirements-train.txt   rented GPU instance — QLoRA training (pinned, see file for why)
#   requirements-infer.txt   rented GPU instance, SEPARATE venv — vLLM batch inference
#
# Install the one matching what you're about to run, e.g.:
#   pip install -r finetune/requirements-local.txt
#   pip install -r finetune/requirements-train.txt
#   pip install -r finetune/requirements-infer.txt
