# Two backends are available for training/inference — pick one:
#
#   CUDA (cloud GPU rental — AWS, RunPod, etc.), files suffixed *_cuda.py:
#     requirements-local.txt        local M3 Max / any CPU machine — data prep, labeling, review
#     requirements-train-cuda.txt   rented GPU instance — QLoRA training (pinned, see file for why)
#     requirements-infer-cuda.txt   rented GPU instance, SEPARATE venv — vLLM batch inference
#
#   MLX (Apple Silicon, runs locally, no cloud/GPU rental needed), files suffixed *_mlx.py:
#     requirements-mlx.txt          local Mac — training AND inference (one env, no CUDA needed)
#
# Both backends read/write the same data files (finetune/data/*.jsonl, schema.json, prompts/)
# and produce adapters that do the same job — pick whichever compute you actually have access
# to. Install the file matching what you're about to run, e.g.:
#   pip install -r finetune/requirements-local.txt      # always, for data prep/labeling
#   pip install -r finetune/requirements-train-cuda.txt  # OR
#   pip install -r finetune/requirements-mlx.txt
